overflow

Esta caja tiene una altura fija y mucho texto adentro. Con overflow: auto aparece la barra de scroll SOLO cuando hace falta. Si pusieramos overflow: hidden, todo el sobrante se cortaria sin aviso. Si pusieramos overflow: visible (el valor por defecto), el texto se derramaria por fuera de la caja y se pisaria con lo de abajo. Texto de relleno para que efectivamente sobre contenido y se note el scroll.
