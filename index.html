Programacion IV — Codigo de clase

UTN — Facultad Regional Mar del Plata

Todo lo que se escribio en clase, ordenado y comentado. Cada carpeta tiene un README.md con los puntos clave y ejercicios: empeza por ahi.

Clase 1 — HTML e introduccion a CSS

  1. Estructura HTML
    doctype, head vs body, metas, encabezados, listas, tablas, enlaces, imagenes, div y span
  2. Box model
    las 3 formas de aplicar CSS, anatomia de una regla, content / padding / border / margin, box-sizing

Clase 2 — Selectores, position y flexbox

  1. Selectores
    clase / id / atributo, especificidad, combinadores, :nth-child, :not, ::before, ::marker, ::selection, !important
  2. Position y z-index
    static, relative, absolute, fixed, sticky, contexto de apilado, overflow
  3. Flexbox
    direction, wrap, justify-content, align-items, gap, grow / shrink / basis, navbar y centrado
  4. Borrador en vivo
    lo que se tipeo en el proyector, sin editar

Clase 3 — Grid, sombras, transiciones y responsive

  1. Grid
    fr, template-columns / rows, template-areas, lineas y span, repeat, grid anidado
  2. Sombras y transiciones
    box-shadow y sombras apiladas, text-shadow, transition, curvas, :hover / :active, prefers-reduced-motion
  3. Responsive
    variables, unidades, clamp / min / max, @media, auto-fit + minmax, container queries
  4. Borrador en vivo
    flex, grid, media queries, clamp y container queries, tal cual salio en clase
  5. Borrador de sombras
    sombras apiladas y la sombra en ::after animada con opacity

Clase 8 — DOM, eventos y formularios

  1. DOM, eventos y formularios
    getElementById, innerHTML, classList.toggle, addEventListener, submit, preventDefault, FormData
  2. Buscador de Pokemon
    integrador: fetch a una API publica, async/await, createElement, menu hamburguesa animado. Necesita internet
